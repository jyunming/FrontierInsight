# Agents

Specialized agent implementations that collaborate within the Frontier Insight pipeline.

Planned agents:

- **Researcher** — generates ideas and frames hypotheses.
- **Experimenter** — designs protocols and writes/executes experiment code.
- **Analyst** — performs statistics, validation, and insight synthesis.
- **Writer** — produces manuscripts, posters, and presentation materials.
- **Reviewer** — critiques outputs and feeds improvements back into the loop.
