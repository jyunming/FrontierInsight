How it works

13 LangGraph nodes orchestrate a research pipeline. Each node is an LLM call or a real Python subprocess. The graph is checkpointed to SQLite, so a crash mid-quest doesn't lose work — --resume picks up where it died.

13-node pipeline

clarify → ideate → literature → design → implement → execute → analyze → cross_check → write → review (loop) → paper.pdf.

Runs real Python

Experiment node spawns a sandboxed venv subprocess. Figures come from real data, not LLM hallucinations.

Literature grounding

Retrieves from arXiv / OpenAlex / Crossref / Axon. Cites by content, not by guessed DOI.

Adversarial review

Multi-persona reviewer panel + a separate critique pass that asks "what did the first reviewer miss?"

Resumable + reproducible

Every quest checkpoints to SQLite. The bundled experiment.py + manifest make the result a complete deliverable.

Cost-aware

Per-call cost logged to .fi/cost.jsonl. Pick per-call (Copilot) or per-token (OpenAI / Claude / Gemini) — UI shows the running total.

Why not just ask an LLM directly?

An LLM with no plan, no experiment, and no review is a guess machine. FI is a research machine.

Asking an LLM directly

  • One call. The model hallucinates.
  • No experiment — pure prose.
  • References are guessed or non-existent.
  • No review. No reproducibility.
  • Output is a chat reply.

Frontier Insight

  • 13 nodes, each with focused prompt + grounded context.
  • Runs real Python in a sandboxed venv.
  • Retrieves from arXiv / OpenAlex / Crossref / Axon. Cites by content.
  • Multi-persona reviewer panel + adversarial critique.
  • Output is a quest directory with paper, code, figures, manifest.

Choose your provider

What lands on disk

Every quest produces a complete directory you can hand to a teammate.

outputs/<quest_id>/ ├─ paper/paper.md # the finished IMRAD paper ├─ paper/paper.pdf # pandoc + LaTeX (or tectonic) ├─ figures/*.png # every plot the experiment produced ├─ code/experiment.py # exact code that ran ├─ slides.md · slides.pptx # optional deliverables ├─ poster.tex · talk.md # optional deliverables ├─ data/auto_collected/ # Axon hits + dataset-adapter output ├─ .fi/run.log # full run log ├─ .fi/state.sqlite # resumable checkpoint ├─ .fi/cost.jsonl # per-call cost ledger └─ frontier_insight_summary.json # machine-readable index
