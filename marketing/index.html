THE PIPELINE

14 nodes. One paper.

Each node is a focused LLM call or a real Python subprocess. The graph checkpoints to SQLite, so a crash mid-quest doesn't lose work — --resume picks up where it died.

clarify ideate literature design implement execute ▶ analyze cross_check write review critique data_load paper.pdf
terminal SANDBOXED PYTHON

Runs your experiment. Doesn't hallucinate it.

The execute node spawns a sandboxed venv subprocess. Figures are rendered from real numbers, not Markdown image links to imaginary files. The bundled code/experiment.py reproduces them on any machine with the requirements.

  • check_circle Subprocess isolation with a per-quest venv.
  • check_circle Auto-dataset adapters for arXiv, OpenAlex, S2, Crossref.
  • check_circle Re-execute lets you tweak experiment.py and re-run.

forum MULTI-PERSONA REVIEW

Adversarial review, baked in.

Three reviewer personas plus a separate critique pass that asks "what did the first reviewer miss?" Iterates until accept or N=3. Every verdict + score lands in the quest summary so you can grep across runs.

  • check_circle Configurable reviewer panel (skeptic / domain / methods).
  • check_circle Score + verdict written to frontier_insight_summary.json.
  • check_circle Iterations diffable via /compare.
save CHECKPOINTED STATE

Crashes don't cost you 40 minutes.

Every node checkpoints to SQLite via LangGraph. Kill the process at analyze, restart with --resume <quest_id>, and you keep all the literature retrieval, the experiment output, and the figures. Reproducibility comes free.

  • check_circle Per-quest .fi/state.sqlite.
  • check_circle Soft-invalidate to re-run downstream nodes.
  • check_circle Cost ledger at .fi/cost.jsonl per call.

COST-AWARE BY DEFAULT

Pay per call, per token, or zero.

Two billing models. The wrong pick can be a 5–10× cost difference on a long quest. Pricing is tracked per call in .fi/cost.jsonl.
